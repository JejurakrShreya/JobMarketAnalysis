## 📌 Project Overview

This project analyzes job market data to understand job demand, salary trends, seniority levels, locations, company sizes, and remote work opportunities.

The project uses Python for data cleaning and analysis, MySQL for SQL-based analysis, and Power BI to create an interactive dashboard.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Jupyter Notebook
- Git & GitHub
